# Sesiones del proyecto

Cada sesión debe concentrarse en un objetivo pequeño. El resumen persistente permite abrir
una nueva conversación sin depender del historial del chat.

## Convención

```text
YYYY-MM-DD-titulo-corto.md
```

## Al iniciar una sesión

Lee:

1. `AGENTS.md`.
2. `docs/00-inicio/00-dashboard.md`.
3. El sprint actual.
4. Las notas relacionadas con la tarea.

## Al cerrar una sesión

Guarda objetivo, trabajo realizado, propuestas, errores, pendientes y próximo paso.

Para avances parciales utiliza la plantilla [[../../templates/PLANTILLA-CHECKPOINT|Checkpoint]].
