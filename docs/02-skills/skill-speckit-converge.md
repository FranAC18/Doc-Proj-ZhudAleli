# Skill — speckit-converge

## Qué hace

Compara el código existente con la especificación, el plan y las tareas, y agrega trabajo pendiente a `tasks.md`.

## Activación

Después de revisar el estado de implementación de una funcionalidad.

## Escritura

Sí, únicamente como ampliación controlada de `tasks.md`.
