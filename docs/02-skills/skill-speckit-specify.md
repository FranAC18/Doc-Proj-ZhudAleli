# Skill — speckit-specify

## Qué hace

Crea o actualiza la especificación de una funcionalidad a partir de una descripción en lenguaje natural.

## Activación

Cuando existe una necesidad que debe convertirse en una especificación funcional.

## Entradas y salidas

- Entrada: descripción del problema y contexto disponible.
- Salida: `spec.md` y, cuando corresponda, checklist de calidad.

## Escritura

Sí. Puede crear o actualizar artefactos de especificación.
