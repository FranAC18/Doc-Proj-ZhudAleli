# Skill — speckit-constitution

## Qué hace

Crea o actualiza la constitución del proyecto y sincroniza sus plantillas dependientes.

## Activación

Cuando se revisan principios, reglas de gobernanza o plantillas globales.

## Escritura

Sí. Modifica la constitución y las plantillas correspondientes.
