# Evidencias del proyecto

Guarda evidencia reproducible y anonimizada por sprint o requisito:

```text
docs/evidence/S1/RF-ACC-001/
├── README.md
├── test-results.md
└── validation-summary.md
```

Cada evidencia indica fecha, entorno, versión/commit, procedimiento, resultado y vínculo al
criterio de aceptación. Las capturas deben ocultar nombres, teléfonos, cédulas, claves y otros
datos personales. No guardes bases de datos reales ni logs completos sin depuración.

Una descripción de “pruebas pasaron” sin comando, resultado y versión no basta para cerrar un
criterio.
