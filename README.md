## Ediciones anteriores conservadas

El [compendio Word v1.0](historias/historias_usuario_tecnicas_pila_v1.0_2026-10-13.docx)
y el [plan Word v1.1](sprints/plan_incremental_y_sprints_v1.1_2026-10-13.docx)
usan la numeración anterior S1–S5 para desarrollo. Se conservan como historial;
para el calendario y las prioridades actuales se usan las ediciones vigentes de
la tabla.

También se conservan las ediciones HU v2.3–v2.4, HT v1.4, pila v1.3–v1.4,
sprint backlog v1.0–v1.1 y plan Word v1.2–v1.3. Las ediciones vigentes usan
fichas individuales y dejan los códigos como referencias secundarias.

El registro de entrevista v1.0 se conserva como antecedente; el registro vigente es v1.1,
cotejado con CAT-REQ-001 v1.2. El acta formal, la validación organizacional directa de las
novedades y la revisión académica continúan pendientes.

La autoría correcta de los documentos Word es Franklin Acero. Se corrigieron
las propiedades de las ediciones anteriores para evitar atribuciones erróneas.

La línea base vigente consta de **58 requisitos funcionales y 9 no funcionales confirmados**, además de RF-COS-001 y RNF-OPS-001 propuestos. El tesista aprobó la edición general v2.0 y CAT-REQ-001 v1.2; la revisión de la directora y la validación directa de la organización para las novedades siguen pendientes. Sprint 0 de preparación está cerrado desde el 21 de julio de 2026. S1 de requisitos y diseño permanece parcial; no se declara terminada la aplicación Django ni ejecutadas pruebas de aplicación.

El tesista informa que el docente de Aplicaciones II revisó requisitos en
clase. El reporte se conserva como tal, sin inventar la fecha, la versión examinada, el
resultado o una constancia. La revisión académica formal continúa pendiente. El alcance
general v1.3 alinea el contenido con la línea base vigente y espera la revisión del tesista;
se conserva como Markdown editable y como Word con el formato de marca y el isotipo original.

El documento general v2.0 es la lista completa vigente para consulta y entrega. Las ediciones funcional y no funcional v1.1 conservan el detalle de la línea base anterior y no reemplazan la lista general vigente. Las ediciones derivan del catálogo interno CAT-REQ-001, que conserva la aprobación y los estados.
Una modificación aprobada de la línea base requiere una nueva versión del
documento general y actualizar este índice y el control de cambios; organizar
requisitos por sprint en otros documentos no reemplaza esa lista general.

## Regla de actualización

Todo cambio documental relevante genera una nueva versión del archivo, una
entrada en el control de cambios y la actualización de este índice. Solo el
contenido de esta carpeta se destina al repositorio documental del docente.
Cada publicación requiere revisión y confirmación del tesista.
