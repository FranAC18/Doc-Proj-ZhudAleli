## Ediciones anteriores conservadas

Las ediciones Word anteriores v1.0–v1.5 de historias y v1.1–v1.6 de planificación
usan formatos o numeraciones previas. Se conservan en el vault del proyecto; este
repositorio publica las ediciones indicadas como vigentes en la tabla.

También se conservan las ediciones HU v2.3–v2.4, HT v1.4, pila v1.3–v1.4,
sprint backlog v1.0–v1.1 y plan Word v1.2–v1.3. Las ediciones vigentes usan
fichas individuales y dejan los códigos como referencias secundarias.

La autoría correcta de los documentos Word es Franklin Acero. Se corrigieron
las propiedades de las ediciones anteriores para evitar atribuciones erróneas.

La línea base documentada en requisitos generales v2.0 consta de **58 requisitos
funcionales y 9 no funcionales confirmados**, además de dos requisitos propuestos.
El tesista aprobó la edición general y la priorización v1.3. La falta automática,
el máximo de tres días hábiles para justificar y la validación de multas por la
Tesorera constan en RF-ASI-006. La revisión académica formal y la validación
organizacional directa de las novedades continúan pendientes; P-03 conserva
detalles abiertos. Tampoco se presenta como terminado ningún sprint, prueba o
aplicación Django.

## Regla de actualización

Todo cambio documental relevante genera una nueva versión del archivo, una
entrada en el control de cambios y la actualización de este índice. Solo el
contenido de esta carpeta se destina al repositorio documental del docente.
Cada publicación requiere revisión y confirmación del tesista.
