Restricciones de uso por contraste

  • --text-muted (#9F93A3) da 2.93 sobre blanco: falla AA. Se usa solo para elementos decorativos, nunca para texto que comunique información.
  • Por eso se añadió --text-secondary (#6B616D), derivado del mismo tono, con 5.91/5.56 para texto secundario informativo.
  • --accent-cyan (2.49) y --accent-yellow se emplean para indicadores no textuales (puntos, bordes) o con texto oscuro de mayor contraste.
  • --danger es un complemento semántico fuera de la paleta de marca, necesario para estados de error accesibles (la referencia solo trae acentos de éxito).

Tipografía
