Restricciones de uso por contraste

  • --za-text-muted (#9F93A3) da 2.93 sobre blanco: falla AA. Se usa solo para elementos decorativos, nunca para texto que comunique información.
  • Por eso se añadió --za-text-secondary (#6B616D), derivado del mismo tono, con 5.91/5.56 para texto secundario informativo.
  • --za-accent-cyan (2.49) y --za-accent-yellow se emplean para indicadores no textuales (puntos, bordes) o con texto oscuro de mayor contraste.
  • --za-danger es un complemento semántico fuera de la paleta de marca, necesario para estados de error accesibles.
