# Alcances modulares

Esta es la carpeta única de trabajo para los documentos de alcance modular,
incluidas sus versiones anteriores, las propuestas vigentes y la plantilla de
formato. Las ediciones académicas aprobadas se prepararán desde aquí y pasarán a
`documentacion/alcance/modulos/` cuando hayan sido aprobadas para entrega. El
alcance general del proyecto permanece separado en
`documentacion/alcance/alcance_v1.2_2026-10-13.md`.
