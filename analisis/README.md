# Análisis internos

Esta carpeta guarda análisis, comparaciones y borradores que ayudan a preparar
documentos finales. No forma parte de la entrega al docente.

Las nuevas notas se agrupan por fecha y tema, por ejemplo
`analisis/2026-10-12/requisitos/`. Cada nota indica su fuente, estado y la edición
final a la que contribuyó, si existe. Un análisis no aprueba requisitos ni decisiones.
